# GTA 6 Meme: WANTED, The Ghost

This repository holds a GTA 6 meme created for make.fun's "Post a GTA 6 meme on X" bounty: a GTA style WANTED poster starring the make.fun ghost. The `meme2.png` image is generated by `make-meme2.sh` using ImageMagick and the `assets/ghost.png` mascot. The X post address is recorded in `POST.json`.

## Run it

```sh
bash make-meme2.sh
node main.ts
```
