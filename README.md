# GTA 6 Meme: Watch Yo Jet Ski

This repository holds a GTA 6 launch-week meme created for make.fun's "Post a GTA 6 meme on X" bounty. The `meme.png` image is generated by `make-meme.sh` using `ffmpeg` to combine a frame from the official GTA 6 Trailer 2 (footage is property of Rockstar Games) with the `make.fun` ghost. The X post address should be recorded in `POST.json`.

## Run it
